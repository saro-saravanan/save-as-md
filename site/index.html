Saving guide

Every save lands in Downloads\WebClips as a folder holding the Markdown file, an assets folder of images, and the page as it was.

Install SaveMD

Coming soon Chrome Web Store listing

Until then, download it and add it to Chrome yourself. It takes about two minutes and needs no other software.

Download SaveMD

  1. Unzip the download, and move the savemd folder somewhere it can stay, such as Documents. Chrome runs SaveMD from that folder.
  2. Open chrome://extensions and turn on Developer mode (top right).
  3. Choose Load unpacked, select the savemd folder, and pin SaveMD to the toolbar.

Chrome may remind you that a developer-mode extension is on; that's expected for anything installed outside the store. Prefer to build it yourself? The source code is on GitHub.

Questions

Is it really free?

Yes, every feature, with no account. It's open source under the MIT license.

Which apps can open what it saves?

Any app that reads Markdown: Obsidian, Typora, MarkText, VS Code and others. The image links point at the local copies, so pages read offline. Open uses whichever app your computer opens .md files with.

Why not save straight into a folder I pick?

Chrome doesn't let extensions keep access to a folder you choose: it ends as soon as the extension's own window closes. So SaveMD saves through Chrome's downloads, which always works. On Windows, a one-line command from the Options page sends saves to any folder.

Does it work on a Mac?

Saving works the same way, into Downloads/WebClips. Sending saves to another folder is Windows-only for now.

What if a page doesn't save well?

Use Pick an area to save for pages that aren't articles, and please tell us about the page. Each saved folder includes the page as SaveMD saw it, which makes fixing it much easier.
