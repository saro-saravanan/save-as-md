Privacy policy

Last updated 2026-10-01

SaveMD collects nothing and sends nothing anywhere. It runs entirely in your browser and writes the pages you save to your own computer.

What SaveMD does

  • When you click save (or use the shortcut or a menu item), it reads the page in that tab and turns it into Markdown.
  • It downloads that page's images, directly from the sites that host them, so they can be saved next to the Markdown. On Reddit threads it also reads the thread's data from Reddit.
  • Chrome writes the files to your Downloads folder. SaveMD never sees or keeps your other files.

What it stores, on your computer only

  • Your settings: how to save each site and how many Reddit comments to keep.
  • A list of pages you've saved (address, folder name and date), so it can ask before saving the same page twice. Undo removes the entry.
  • On Windows, the folder you typed for the folder link, so the box is filled in next time.

These stay in Chrome's storage for the extension. Removing SaveMD deletes them.

What it never does

  • No analytics, tracking, ads or account.
  • No server: nothing you save, and nothing about you, is sent to the developer or anyone else.
  • It doesn't read pages you haven't asked it to save.

Why it asks for these permissions

PermissionWhy
Read and change data on all sitesTo read the page you ask it to save, and to download that page's images from wherever they're hosted.
Manage your downloadsTo write the saved page and its images into Downloads\WebClips, open a saved file, show its folder, and undo a save.
StorageTo keep the settings and saved-page list described above, on your computer.
Context menus, scripting, clipboardFor the right-click menu items, to run the save on the page, and for Copy as Markdown.

This website

This site has no analytics or cookies, and its fonts are served from here rather than from a font service. It's hosted on GitHub Pages, so GitHub may keep standard server logs under GitHub's privacy statement.

Questions

SaveMD is open source, so you can read exactly what it does. Questions or concerns: open an issue on GitHub.
