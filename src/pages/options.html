SaveMD

Where saved pages go

Every page is saved through Chrome's downloads into Downloads\WebClips, one folder per page.

Saving into a folder of your choice

Chrome won't let extensions keep access to a folder you pick, so instead point WebClips at your folder with a Windows link. From the SaveMD project folder, run:

npm run link -- "C:\Users\you\OneDrive\Clips"

Pages already in WebClips are moved into your folder first. Chrome then writes through the link, so new pages land in your folder with no prompts. Run it again with a different folder to change it.
