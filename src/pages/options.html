SaveMD

Where saved pages go

Every page is saved through Chrome's downloads into Downloads\WebClips, one folder per page.

Saving into a folder of your choice

Chrome won't let extensions keep access to a folder you pick, so instead point WebClips at your folder with a Windows link. It takes one pasted command:

  1. Press Windows + X and choose Terminal.
  2. Paste with Ctrl + V and press Enter.
  3. It answers Linked … -> …. New pages now land in your folder.

Pages already in WebClips are moved into your folder first; nothing is deleted. Run it again with another folder to change it.

Linking a folder is Windows-only for now. Saved pages stay in Downloads/WebClips.

Keyboard shortcut

Default Alt+Shift+S. Change shortcut

Opening saved pages

The notice's Open button opens the .md with your Windows default app for Markdown files. To change it, right-click any .md file → Open with → Choose another app, and tick Always use this app.
